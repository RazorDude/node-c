- [Adding a permission](./adding-a-permission.md) - give a role access to a route, with fine-grained rules
- [Seeding data](./seeding-data.md) - initial and test data that runs with the migrations
- [Logging in with Okta](./okta-login.md) - OAuth2/OIDC login with PKCE
- [Federated login](./federated-login.md) - one SSO app that other NodeC apps log users in through
