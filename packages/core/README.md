# Node-C / Core
This is Node-C's core package. It provides the architectural outline classes, and common functionalities and interfaces for building BE apps with the framework.

The documentation can be found in the [Node-C docs](https://github.com/RazorDude/node-c/blob/master/docs/index.md) - see [Configuration](https://github.com/RazorDude/node-c/blob/master/docs/Fundamentals/configuration.md), [Domain services](https://github.com/RazorDude/node-c/blob/master/docs/Overview/domain-services.md) and [Core utilities](https://github.com/RazorDude/node-c/blob/master/docs/Fundamentals/core-utilities.md) for this package.
