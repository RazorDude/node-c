# Node-C / Data: RDB
This is Node-C's package providing the functionality for relational databases that TypeORMDB can work with. Currently, PostgreSQL and MySQL are supported.

The documentation can be found in the [Node-C docs](https://github.com/RazorDude/node-c/blob/master/docs/index.md) - see [Relational databases](https://github.com/RazorDude/node-c/blob/master/docs/Data/rdb.md) and [Query filters](https://github.com/RazorDude/node-c/blob/master/docs/Data/query-filters.md) for this package.
