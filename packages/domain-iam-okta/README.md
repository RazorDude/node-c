# Node-C / Domain: IAM Okta 
This is a plugin for Node-C's "Domain: IAM" package. It adds Okta auth to the standard set of authentication methods provided by the "Domain: IAM" package.

The documentation can be found in the [Node-C docs](https://github.com/RazorDude/node-c/blob/master/docs/index.md) - see [Authentication](https://github.com/RazorDude/node-c/blob/master/docs/Architecture/authentication.md) for this package.
