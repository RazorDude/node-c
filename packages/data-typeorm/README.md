# Node-C / Data: TypeORMDB
An implementation of Node-C's Peristance: RDB package, providing the functionality for relational databases that TypeORMDB can work with. Currently, PostgreSQL and MySQL are supported.

The documentation can be found in the [Node-C docs](https://github.com/RazorDude/node-c/blob/master/docs/index.md) - see [Defining entities](https://github.com/RazorDude/node-c/blob/master/docs/Data/entities.md) and [Relational databases](https://github.com/RazorDude/node-c/blob/master/docs/Data/rdb.md) for this package.
