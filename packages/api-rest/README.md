# Node-C / API: REST
This is Node-C's package for setting up REST API modules on top of the HTTP API modules.

The documentation can be found in the [Node-C docs](https://github.com/RazorDude/node-c/blob/master/docs/index.md) - see [Controllers](https://github.com/RazorDude/node-c/blob/master/docs/Overview/controllers.md) for this package.
